How it works

  1. 1
    You describe the task

    In plain language, in English or Portuguese, with the page's link.

  2. 2
    A local LLM plans it

    A small model on your computer writes the steps. It never acts.

  3. 3
    The code acts and checks

    Each step is done, checked and, if the page changed, recovered. Sensitive steps wait for you.
